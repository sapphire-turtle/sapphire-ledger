# sapphire-ledger-cli

The command line of [sapphire-ledger](https://github.com/sapphire-turtle/sapphire-ledger)'s
two editions: its commands (`init`, `check`, `account`, `tx`, `assertion`, `price`, `panel`,
and sapphire-framework's `serve`, `status`, `service`, `workspace`, `mcp`, …), the app server
and the MCP server, as a library.

To install the command, see [`sapphire-ledger-headless`](../../README.md#installation) (no GUI)
or the desktop app; both put `sapphire-ledger` on PATH.
